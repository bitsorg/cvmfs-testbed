Detects publish events by polling Stratum 0's .cvmfspublished every 5 s. Each new root hash = one commit.
MQTT is not active on this testbed. The MQTT control-plane is not configured — restart the testbed with ./testbed.sh server --mqtt (or make MQTT=1 start) to enable it. Monitoring via S0 polling below will still work for detecting root-hash changes.
The browser cannot connect to the raw MQTT socket. This page tracks hash changes via S0 polling; the MQTT broker delivers them to receivers. Start polling to see live events.
