Time per Pipeline Stage (avg, seconds) ▼
Average wall time per phase for completed bits (prepub) jobs. Pipeline: compress + dedup + CAS upload. Lease+Commit: waiting for per-repo commit slot + gateway lease + catalog merge + commit (serialised per repo — high values with concurrent jobs indicate mutex contention). S1 Distribution: async S1 pre-warming queued at publish time; timer ends when all endpoints confirm — may finish after Published. Hover bars for exact values. Only jobs with per-stage timestamps are included. Per-job breakdown is available as a tooltip on the Duration cell in the Jobs table.
